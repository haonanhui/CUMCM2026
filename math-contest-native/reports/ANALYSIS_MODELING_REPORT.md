# 赛题分析与建模报告

根据题目动态调整问题数量。本赛题共 3 个子问题。

## 总体框架与数据
输入为六个算子的 DAG，节点分 ALLOC、FREE 和操作节点。源 DOCX 正文已提取到 data/derived/npu2025/statement.txt，公式文字提取不作为图形的完整替代。原件复制及哈希见 provenance/npu2025_inputs.json。节点数为 1716 至 36086，边数为 2712 至 85653；实际读取、重复检查与 CSV/JSON 逐字段比对记录在各 run 的 audit.json。Size 使用题面容量单位，不擅自解释成字节。

总体路线：图结构审计 → 拓扑操作顺序 → 生命周期收缩 → 连续缓存分配与换入换出 → 加入内存复用边 → 分执行单元流水重放 → 同搬运量约束下择优。

## 假设敏感性预检
### 模糊表述及解释
1. 问题一“驻留缓存容量”可能理解为各缓存单独峰值，也可能理解为题目给出的总和。采用题面递推公式的所有类型总和作为主目标，另报告分类型峰值。问题一不强加问题二的缓存容量约束。
2. 附录 C 的 FREE→ALLOC 地址复用边只直接覆盖未换出的生命周期。若 SPILL 后仍按原 ALLOC/FREE 整段加边，会出现 FREE 晚于换入却要求先 FREE 才能复用的环。采用驻留段：ALLOC/IN 占用，OUT/FREE 释放；旧释放节点→新占用节点，并保留原 DAG 的全部边。
3. “搬运量不显著增加”没有量化阈值。取最保守的零增加约束 D3≤D2，而非人为放宽阈值。
4. ALLOC/FREE 时间为零；同一硬件单元按序列顺序执行，不同单元可重叠。序列不是所有操作的全局串行时间表。

### 快速验算与递进性检查
没有物理容量限制时无需 SPILL，问题一可纯拓扑优化。引入连续地址后，驻留总量低不保证单类型无碎片；问题二因而仍有独立意义。降低峰值可能减少流水并行，问题三仍有改进空间。驻留段解释在无 SPILL 时退化为题面 FREE→ALLOC 规则。

### 最终解释及对照图
报告总峰值和各类型峰值、所有候选的时间—搬运量散点、六图峰值对比、代表算子的流水图。问题三没有改进的实例如实报告 0，不凭目标函数宣称有效。

## 符号
G=(V,E)，N=|V|，B 为缓冲区集合。b 的大小为 s_b，类型为 t_b，容量为 C_t。π(v) 为序列位置，a_b、f_b 为分配与释放节点。x_b 是初始偏移，x_bj 是第 j 次换入偏移。c_v 是周期，p_v 是执行单元。

## 问题一
目标 min H，H=max_k Σ_b s_b·1{π(a_b)≤k<π(f_b)}，约束 π(u)<π(v) 对所有依赖边成立；所有节点恰好一次。该组合优化在大图上采用启发式，不宣称全局最优。

在操作诱导 DAG 上维护入度和就绪集合。ALLOC 尽量延迟到首次使用之前，FREE 在所有使用及显式前驱完成后立即执行。只有原题根 ALLOC、叶 FREE 结构经过检查后才应用此变换。每步从最小编号的 W 个就绪操作中选取 new(v)−α·release(v) 最小者，同分按新增量、下游关键路径和编号排序；new 为首次使用但尚未分配缓冲区的总量，release 为操作后最后使用的总量。比较 W=32、64、128 与 α=1、2，同时保留编号基准。参数为全图统一的候选组合，不按算子特化。

当前实现每步扫描就绪集合构建窗口，保守复杂度 O(N² log W + E)，空间 O(N+E+Σ|Bufs|)。窗口只限制评分候选数，不把集合扫描误称 O(N log N)。关键路径在逆拓扑序线性计算。输出序列和峰值。

## 问题二
对每个驻留段约束 0≤x≤C_t−s_b，同类型重叠驻留段的连续地址区间必须不相交。目标 D=Σ_spill s_b·(1 或 2)，有 COPY_IN 使用者系数为 1，否则为 2；严格依题面判断，不从操作名推断读写方向。

采用最佳适配空闲连续区间。无可用区间时从当前操作不使用的同类型驻留缓冲区中选牺牲者，比较两种策略：下一次使用距离最大；距离/换出代价最大。释放其地址并插入 SPILL_OUT，直到申请满足；下一次使用前插入配对 SPILL_IN 并记录新偏移。每次 OUT/IN 的编号严格为 N+2j、N+2j+1。支持多次换出，同一缓冲区的驻留段不能重叠。候选失效时保留失败记录，不带病进入论文。

容量按题面固定：L1=4096、UB=1024、L0A=L0B=256、L0C=512。操作同时引用的缓冲区总大小若超过该类型容量，直接报告不可行。连续区间离散扫描成本 O(C_t)，总体还受换出次数 M 影响；不把缓存长度看成任意输入时的常数。

## 问题三
构造流水优先候选：就绪操作按预计最早开始时间+α·new(v) 排序，同分优先下游关键路径长者。该预测不含地址复用等待，最终只能以完整重放评价择优。候选仍经问题二分配器处理。

评价对原始边、驻留段复用边、SPILL 生产/消费边和同单元顺序求最长路：start(v)=max(所有前驱结束时间,同单元前项结束时间)，end(v)=start(v)+c_v，T=max_v end(v)。换出耗时对 COPY_IN 缓冲区为零，否则 2s+150；换入统一为 2s+150。选择 D≤D2 的候选中 T 最小者。下界为各单元总工作量与原图关键路径的最大值（只作下界，不作最优证明）。

## 最终实现补充
实际搜索增加正序/逆序前驱 DFS，共八种操作顺序；每种比较两种换出准则并对距离准则加入地址轮换，每图二十四候选。问题三还将已验证方案转换为仅含原始、驻留复用及换出使用依赖的 DAG，移除隐含的固定执行单元顺序约束后重新列表调度。保留全部物理驻留顺序，故不改变搬运量；重排后按 OUT 出现先后重新配对编号。该阶段按执行单元维护关键路径优先堆，比较最早启动和纯关键路径策略。

小图测试已落实并通过：独立单元重叠 20 周期、地址复用后 30 周期、输入/中间缓冲区换出 4/8 单位及 188/346 周期；四类错误附件均被拒绝。未实施大图精确最优求解。最终运行与局限见 RESULTS_REPORT 和 VERIFY_REPORT。
