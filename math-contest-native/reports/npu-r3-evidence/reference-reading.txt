三种策略中关键路径调度策略生成的初始解是最优的，因此这里仅讨论关键路径调度
策略＋模拟退火算法相对于节点总数 N 的时间复杂度，E 为图的有向边数量。
对于关键路径调度策略， 计算每个节点v 的高度方法是使用拓扑排序的逆序递推算法，
即以出度为 0 的节点队列开始迭代，该流程的时间复杂度为 O(N + E) ，计算完每个节点
的高度后，该算法就绪节点集 Q 由普通队列替换为优先堆，取节点和插节点的复杂度从
O(1) 提升为 O(log ·N ) ， 因此时间复杂度变为O((N + E) log ·N ) ， 因此该策略时间复杂度
为 O((N + E) log ·N ) 。对于模拟退火算法，由于 E ≪ N 2 ，该计算图为稀疏图。计算循
环次数 K = O (logα Tinitial /Tfinal ) ， 内层每个温度的迭代次数为L ， 单次迭代的核心操作复
杂度仅为 O(N ) ，模拟退火算法时间复杂度为 O(KLN ) = O(N )（K, L 为常数） 。
综上所述，整体算法的时间复杂度为 O((N + E) log ·N ) 。
