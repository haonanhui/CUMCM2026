# 独立运行与数字绑定

`scripts/run.py` 使用 Python 标准库，不依赖 app。输入是 JSON 配置，示例 `examples/mean/config.json`。

- `argv`：实际命令参数数组，无 shell 拼接；`{python}` 替换当前解释器，`{run}` 替换新运行目录。
- `inputs`、`sources`：相对于项目根的非空文件列表；包含数据、全部执行代码、导入的自有模块和依赖锁文件。脚本只校验显式列出的文件，未声明依赖不在覆盖范围。
- `expect`：相对于 run 目录的非空结果文件列表，不允许越界、空文件或占用证据文件名。
- `timeout_seconds`：单条命令的超时，默认 300。实验命令应为同步单进程入口，不自行后台启动；超时不构成任意孙进程已回收的证明。

运行命令：`python scripts/run.py --config <相对配置路径> --id <新的标识>`。

工具在 `results/runs/<id>/` 保存配置快照、执行前输入/源码哈希、实际 argv、解释器、日志、退出码、预期结果哈希与错误。执行前后输入或源码改变则 FAIL。`EXECUTED` 只说明显式命令正常结束、声明文件稳定且声明输出非空；科学验证永远由独立报告承担。

工具不沙箱化求解器：argv 是可信研究代码，求解器仍可能读写其他路径。它不保证捕获未声明依赖或中途修改后恢复的文件。执行期间保持输入与代码不变；严格重现时用固定 Git commit/源码副本、依赖锁和只读输入副本。

本地计算需输出结构化 `numbers.json`，每个实际指标记录值、单位、来源字段和验证口径。`paper/bindings.json` 指向已审核 run 的指标与文件哈希；不要将合成演示数字写进真实绑定。论文重算或变更数据后重新核对绑定。

结果进入论文的检查至少包括：已知基线/解析小例、约束可行性、量纲、边界、误差/容差、必要的敏感性，以及每个问题的覆盖。复跑一致只证明复现性，不证明模型正确。

共享大结果可放受控队内存储，保留相对定位、字节数与 SHA-256；队友验收时重新取文件核对。提交只按赛事允许清单挑选文件，不压缩整个工作区。
