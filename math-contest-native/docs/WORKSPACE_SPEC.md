# 原生 Harness 数模竞赛工作区

版本：1.0，2026-09-20。用户授权另建本目录，作为可独立完成竞赛的主工作区。

## 目标和边界

Codex、DSH 和其他可读写本地文件的 agent 共用项目文件、技能正文、角色说明、任务交接与研究证据。模型执行和工具调用归各自原生 Harness；本目录不依赖桌面工作台、bridge、MCP pipeline、app 数据库或 UI 停点。

工作区级规则、技能和角色均由本目录持有。个人登录、模型选择、服务端能力与全局配置属于用户已有 Harness 环境，不复制密钥，不承诺各 Harness 的权限和子 agent API 完全相同。

## 模块与唯一权威

| 模块 | 权威路径 | 写者与边界 |
|---|---|---|
| 工作约定 | AGENTS.md | 项目维护者；其他入口仅指向它 |
| 当前赛事及集成状态 | PROJECT_STATE.json | 当班集成人；不存聊天历史 |
| 技能正文 | .agents/skills/*/SKILL.md | 技能维护者；两个 Harness 共用，不生成第二份正文 |
| 角色职责 | agents/*.md | 角色维护者；可由主会话读取，也可交给原生子 agent |
| 任务与恢复 | team/tasks、team/handoffs | 当前 owner；修改前重读 revision |
| 实验管理 | scripts/run.py | 本地命令，创建独立 run，保存命令、输入与代码指纹、日志和输出指纹；不判断科学正确 |
| 环境与结构检查 | scripts/doctor.py | 只做检查与临时可写性探测；不安装、不改全局配置 |
| Loader 探测 | scripts/probe_codex_skills.py、probe_dsh_skills.mjs | 仅调用技能列表/正文读取，不创建模型回合；独占短命探测进程 |
| 工具链合成演练 | scripts/selfcheck.py、paper_smoke.py | 隔离临时沙箱/独立样例 run，证据明确标注 synthetic |
| 科研代码 | code/data_io、models、solvers、validation、reporting | 按任务显式分配；模块间走 code/interfaces |
| 论文结果绑定 | paper/bindings.json | 写作/集成人；每个数字关联 run、产物和键名 |
| 来源清单 | provenance/ | 来源与改写记录；第三方许可独立登记 |

## 协作与复现

三名队员各自工作副本，Git 同步代码、清单和文稿。单机同时运行多个 Harness 时，每个任务明确写范围；共享状态和论文绑定串行修改。对话不能替代 handoff。

每次实验新建 run。输入与代码在执行前后校验；执行失败或发生变化必须留证，不能计入成功。退出码 0 只证明程序正常结束。科学验收由独立验证记录说明题意、量纲、基线、边界、容差、敏感性和覆盖缺口。

正式规则由具体赛事当年的原始文件确定；未绑定赛事时不得预填固定页数、模板或 AI 政策。重大模型选择和最终提交按用户明确授权处理；已授权普通工作连续推进，不创建 app UI 人工停点。

绘图定制：图内文字统一中文，公式符号除外；按 docs/FIGURES_ZH.md 覆盖上游按论文语言切换的图内语言约定。实际中文字体、缺字警告和最终图件需验收。

## 本轮验收

1. 独立 Git 根、相对路径、无外部开发仓库运行依赖；现有两个工作区不改。
2. 共用技能目录、角色索引、Codex/DSH 启动和接续说明齐备；声明区分文件可读、loader 可见和真实模型读写。
3. 本地 doctor、标准库合成实验、二次独立 run 比对通过；失败命令和重复 run 被正确记录/拒绝。
4. 非空输入与输出、源文件变化、路径越界均有直接检查；保留证据。
5. skills frontmatter 检查通过；不含必须调用 app 工具或点击 UI 的指令。
6. 未执行的真实 Harness 模型调用、队友设备、官方赛题求解及最终论文验收保持 UNVERIFIED。实际编译的合成论文单独记录，不冒充官方模板验收。

工作区工具验收不代表已经具备特定赛事的提交资格；正式赛前需在实际设备完成 docs/PREFLIGHT.md。
