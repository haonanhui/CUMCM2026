# internal-v3.1：逐项评分锚点与评审方法

版本 internal-v3.1，2026-09-21。当前评审必读；24 子项及总计 100 分权重沿用 v2，改变的是证据判定和等级锚点。此为本地研究质量量表，不是 MathModelAgent 或赛事官方评分。历史报告保留原版本，不能用新标准直接换算旧分。

## 评分顺序

1. 固定 PDF 哈希、题面、结果版本与适用格式；记录评审者为自审或独立评审。阅读全文和最终版面，先记缺陷，再评分；不设置期望总分。
2. 建立逐问内容矩阵：对象与困难、变量与约束、关键推导、算法操作、结果、对照、解释。每格写 PDF 页码和具体证据，以及充分/部分/缺失/未核验。论文读者所需的方法和解释应在正文；附录可承担长代码、全量结果和展开证明，正文应有对应概述和指引。内部日志不能代替正文内容。
3. 对 A1–A3、B1–B4、C2–C3、D2 按题面问题分别评分，先固定题面明确权重；无明确权重则各问等权。逐问等级保持 0–4 整数，子项为各问加权分，不把加权等级四舍五入后再算。其余子项按整稿评审。未核验格保留对应权重为 U，不因其他问优秀补齐。
4. 使用下表锚点给等级。0=已查实缺失或根本错误；1=名称/形式存在但核心缺失；2=有实质内容但仍需补推导、分析或重组；3=充分完成，只需局部表达或版面修改；4=满足 3，且具备本项额外质量证据。未知不是 0，记录 null。
5. 分数与缺陷逐项交叉检查：若“下一步”仍需补该项核心内容，不能同时评 3/4。记录支持证据及最强不利证据；同一材料支持不同子项时说明不同贡献。增加免责文字不补足实验，增加公式数不补足推导。
6. 算术分按主规范计算，另报候选状态。存在已证实的核心模型/结果错误或伪造，状态 FAIL；任一关键问论证链或主要结果解释尚需实质补写，状态 NEEDS_REVISION；未核验影响结论，状态 UNVERIFIED；充分完成且只有局部问题，状态 REVIEWED_MINOR_EDITS；无已知待改问题为 REVIEWED_COMPLETE。正式提交状态单列，受赛事规则约束。状态取最严重的已知缺陷，同时保留未知项。

## 24 子项锚点

表中“至多 2”指该缺陷经实际阅读确认，且实质影响本项；轻微孤立问题不一刀切。若仅剩形式或核心错误，则分别降到 1 或 0。

| ID/权重 | 3 档：完整完成 | 4 档额外证据 | 缺陷及档位约束 |
|---|---|---|---|
| A1/5 | 各问输入、目标、要求输出均有正文答案 | 完整覆盖难例/特殊要求并说明其处理 | 主要输出缺失至多1；附件存在不能代替正文答案 |
| A2/5 | 数值、比较条件及研究解释对应题问 | 定位差异的阶段/对象，并有针对性证据 | 只有结果表或泛泛“改善”至多2 |
| A3/5 | 问间输入输出、约束变化和范围清楚 | 解释约束变化如何影响后问选择，含具体比较 | 只有重复限制声明至多2；重复免责不额外得分 |
| B1/5 | 变量、域、单位和必要辅助量可无歧义理解 | 复杂索引/状态关系仍清晰一致，便于复建 | 关键变量或单位缺失至多2；不强求符号全部进总表 |
| B2/8 | 目标、可行域、约束与题面一致且足以定义问题 | 关键边界情形纳入形式表达，模型闭合可核查 | 核心约束遗漏/错置按影响给0–1；不强制写成整数规划 |
| B3/6 | 必要假设有依据，关键转换有成立条件及论证 | 难点证明或反例明确界定适用范围 | 结论直接跳出、关键转换无依据至多2 |
| B4/6 | 方法选择针对本题，操作步骤/参数/终止规则可理解 | 与合适备选或复杂度权衡有具体证据 | 启发式名称加公式、步骤跳跃或参数无来源至多2 |

| C3/5 | 针对关键参数/假设的辨识性检验及解释 | 激活条件、稳定区或失效边界有有针对性的证据 | 参数表存在但作用未解释至多2；不同题型可用合适稳健性检验 |
| D1/3 | 摘要准确覆盖问题、方法、代表结果和结论 | 主线突出，读者能理解最重要的研究发现 | 数字堆积或免责占据结论、遗漏核心问至多2 |

| D3/3 | 篇幅分配跟随研究难点，过渡有内容联系 | 全局主线清楚、层次有节奏且各问充分 | 主要章节需扩写/重组至多2；页数只诊断、不直接赋分 |
| E1/3 | 术语、符号、指代一致且句义明确 | 复杂关系表达准确简洁，跨章节自然一致 | 反复歧义影响理解至多2 |
| E2/4 | 主张强度与证据匹配，条件在合适位置交代 | 精确表达证据强弱且全文自然，以研究结论为主体 | 系统性重复免责或无证据归因至多2；“多次否认”不是4档理由 |
| E3/3 | 连续学术论述，段落围绕对象和研究问题 | 段落递进与信息密度好，需修改仅为局部措辞 | 全文需语体重写、审计腔/模板化反复至多2 |
| F1/4 | 图型、轴、单位、比较基准适合研究问题 | 多尺度/多组信息清晰呈现并帮助发现差异 | 不当归一化或尺度造成实质误导至多1 |
| F2/3 | 图表有研究问题、引用、说明及结果解释 | 图文共同展开机制或局部差异，并回接本问 | 只有题注和数值复述、解释明显不足至多2 |
| F3/3 | 最终尺寸下所需细节、符号与颜色层级可辨 | 跨图视觉一致，密集图有恰当分面/放大且比较便捷 | 承担论证的细节看不清至多2；无裁切不自动等于高质量 |

| G3/3 | 实页均可读，无影响阅读的分页和排版缺陷 | 全文疏密均衡、图文邻接及换页细节精良 | 关键元素重叠/缺字按严重程度0–1；未看实页为null |

## 结果呈现与高分条件

### internal-v3.1 语言与图件的操作判据

本轮细化 v3 的 E/F/G 锚点，24 项权重保持 100 分。旧版 82.17 等历史分数保留；新版需要重新阅读全文及最终 PDF 后独立计算。

- E1：逐处定位抽象把字句，尤其把……化。关系和动作具体、指代清楚才达到 3；反复空泛转换造成理解负担至多 2。单个孤立措辞按局部问题记录，不采用命中一次固定扣分。
- E2：主张强度与证据相称，同时正面陈述适用对象和结果。补充性否定、预防性辩解系统出现则至多 2；严谨性不按免责声明数量奖励。必要约束、反证和零结果正常评价。无依据的算法优越性仍按过度宣称处理。
- E3：研究叙述从困难到方法、比较及解释自然推进。全篇仍需清除防御性语体、口语把字句或强调性引号时至多 2，状态 NEEDS_REVISION。用户规定的零修辞引号单列合规结果：成品任一残留均待修；少量局部问题按实际程度评分，候选可为 REVIEWED_MINOR_EDITS，但不能标 REVIEWED_COMPLETE 或新语言要求通过。
- F2：图题、分面说明和读图必要条件位于图下 TeX caption，结果与机制位于后续正文，正文有相应引用。图内顶部/底部重复说明或图文无解释按影响评档。详细图注有实际读图功能时不因长度自动扣分；删空图注也不加分。
- F3：按最终论文尺寸检查各图字体、基准字号、分面编号、留白和符号的一致性。图中文字在实际尺寸不可读或大量重复装饰干扰观察至多 2。期刊感不是模仿英文图、缩小字号或删除必要图例。
- G1：官方通用条款、官方明确图件条款与本项目保守解释分别记录。研究生赛要求不能由本科赛或期刊字号替代；官方未单列图内例外不等于已授权豁免。G3 负责实际嵌图后裁切、题注邻接和字体可读性；同一缺陷跨项时说明不同影响，不机械重复扣分。

审读同时检查源文本、图内文本与最终 PDF；范围包含标题、摘要、正文、图表、参考文献及作者编写的附录叙述。引号用途由语义判定，代码定界符、数学撇号和原始材料不是修辞引号。报告列源行/PDF页码、实际句子、问题功能、改写与保留事实；扫描数量不等于分数。

| 精确输入形状 | 合格处理 |
|---|---|
| 六图统一规则后补充不按名称特判 | 保留统一设置事实，移除补充否定；不虚构公平性实验 |
| 没有回溯所以高效但受限 | 直接写固定地址链、优化变量和复杂度依据；保留搜索域 |
| 术语大量套引号、把多个对象显式化 | 术语直接定义；分别写具体模型关系，成品引号零残留 |
| 删除所有否定后隐去必要科学条件 | E2 仍不合格，恢复条件并用直接陈述组织 |
| 图源字号12pt但嵌入缩到8pt | 最终字号不符合 figure-style-2，修图后再验证 |
| 图件无上/下说明，caption含分面解释 | 组织符合偏好；还须审查数据、单位、字体及机制解释 |

这些用例用于规则一致性核查，不冒充新版 PDF 已通过或已完成独立评审。

报告每格：子项/题问/分配权重/等级或null/得分/PDF位置/支持与不利证据/实质或局部缺陷/修复动作。逐问表后汇总24项与8维；U>0时总分null，保留 S 与 [S,S+U]。读过不等于完成核验，重复自评不等于独立校准。

90分及以上为“高分候选”，须 U=0，逐问 B2/B3/B4/C2/D2 均至少3，A2/D3/E2/E3/F2/F3均至少3，无实质待改问题，并提供同题或相近题型的优质/较弱段落对照说明。否则保留算术值，标记“评分与证据冲突，复核中”，不发布高分结论；从冲突子项重查，不任意调总分或设隐藏封顶。即使低于90分，存在实质缺项也须返修。

比较参照采用近期同赛事同题型优先、三年半衰期，保留原始统计。参考样本只能校准已读的组织、语言和视觉功能；未经科学审查的“优秀论文”不能作为数学正确性的金标准。需要多篇、多轮及独立人工评分才能估计量表一致性；当前不宣称已具备获奖预测效度。

## 本次故障形状回查

| 输入情形 | 新标准预期 |
|---|---|
| 文件齐全、编译过、只有方法名和表格 | 工程可能通过；B4/A2/D2/F2按正文缺项为1或2，质量返修 |
| 多处“不能证明、不是……”且没有新增内容 | E2/E3按实际语义降低，不能因免责充分满分 |
| 只有一问展开很好，另一问只有结论 | 分问打分，薄弱问保留缺项并触发返修 |
| 未看PDF页面或未核实规则 | G3或G1为null，相应权重进入U |
| 改字号、加空白、附录增加二十页 | 同样内容不增加任何子项得分 |
| 科学约束必要的否定句 | 按意义保留，不按“不”字扣分 |
| 补一句边界说明但仍无有效对照 | E2可准确，C2仍按对照缺口给分 |
| 精炼但论证充分、有可核验结果 | 不因短直接扣分；逐格说明充分性 |

以上是规则一致性反例，不冒充对真实稿件的新一轮盲评。
