# 赛前实机演练

工作区骨架检查与真正参赛验收分开记录。每台队员设备在开赛前完成一次，不把主理人机器结果套到其他机器。

1. 在独立工作副本打开 Codex/DSH，确认实际 cwd、身份、根指令与技能发现；分别读取一个技能并在 `.local/` 写回标识。记录 Harness 版本与输出路径，不保存密钥。
2. 在 Codex 创建一项小任务和 handoff，关闭该会话，在 DSH 只凭项目文件接续，再反向重复。确认没有依赖聊天历史或 app 工具。
3. 使用已知答案的小数据跑完整求解、独立复算、作图与论文编译。第二个新 run 复现关键数字，保留命令、版本和比较结果。
4. 断网时验证本地求解与编译；模型服务断网不可用是外部依赖，需保留人工可运行命令与检查点。所需 TeX/Typst/Python 依赖在赛前安装，避免临赛动态拉包。
5. 在另一台队员设备从共享仓库与受控数据副本重现；确认 Git 冲突处理、结果传输、数据哈希、论文绑定一致。
6. 绑定实际赛事当年规则，核验 AI 使用、外部数据、队内协作、论文格式、匿名性、提交文件/大小/时间窗口；保存官方来源。
7. 候选 PDF 逐页查看，核对摘要数字、公式、表格、图件、引用与附录。冻结确切字节、文件清单和哈希，用户审查最终版本后提交，回执另存。

每项记录 PASS/WARN/FAIL/UNVERIFIED、设备、时间、输入版本、操作、证据、未覆盖项。真实赛题/规则未确认时不宣称 submission_ready。
