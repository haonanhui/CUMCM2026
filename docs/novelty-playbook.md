# 算法新颖性策略手册（Novelty Playbook）

> 定位：Stage 02/03 的战术参考。机制（delta 四层声明 + 裁定规则）见 `code/pipeline/stages/03_model_novelty.md`，工具是 `lib/novelty_gate.py`。本文回答"去哪找 delta"。
> 原则：**新颖性 ≠ 新名词**。评委看的是数学差异：你比烂大街 baseline 多刻画了什么、多证明了什么。delta 层优先级 b(模型) > d(验证) > c(数据) > a(方法)。

## 一、按题型的新颖性杠杆

| 题型 | 烂大街 baseline（先例频率=高） | 高价值杠杆（b/c/d 层） |
|---|---|---|
| 优化/调度 | 加权 LP、GA/PSO 直接跑 | b: 多目标 Pareto 前沿（NSGA-III/MOEA-D）替代单目标加权，刻画目标冲突结构；b: 鲁棒优化/机会约束处理不确定参数；c: 从数据拟合约束系数而非拍脑袋；d: 决策变量扰动下的敏感性 + 解的稳定性证明 |
| 预测 | 灰色 GM(1,1)、ARIMA 单模型直出 | b: 残差修正/组合预测框架（ARIMA 拟合线性 + XGBoost 拟合非线性残差）；d: 滚动回测报告区间覆盖率而非单点 RMSE；c: 外生变量引入（天气/政策） |
| 评价 | AHP+熵权+TOPSIS 三件套 | b: 权重不确定性传播（Monte Carlo 采样判断矩阵 → 排序置信度）；d: 结论对权重扰动的 Kendall tau 稳定性；b: 用 ELECTRE/_PROMETHEE 刻画不可比性 |
| 图论/网络 | Dijkstra/最大流直跑 | b: 时变网络/随机边权建模；b: 复杂网络指标（介数/社团）解释结构成因；d: 剪掉关键边后的网络韧性分析 |
| 机理/仿真 | 直接 ODE/PDE 数值解 | b: 参数辨识反问题（拟合 + 置信区间）而非固定参数；d: 量纲分析 + 收敛阶验证；b: 随机性建模（Monte Carlo + 方差缩减：对偶变数/控制变量/重要抽样） |
| 几何/连通（如华数杯A类渗透导通） | 蒙特卡洛撒点 + 频率统计 | b: 渗流理论标度律（临界体积分数附近 P~|φ-φc|^β）替代黑盒模拟；b: 周期边界/贯穿重叠的显式几何修正；d: 有限尺寸效应分析 + 外推 |
| 综合决策 | 各问独立建模 | b: 跨问耦合（问N 的输出作为问N+1 的约束分布而非点值）；d: 端到端不确定性传递分析 |

## 二、通用加分动作（任意题型可用）

1. **不确定性传递**：把中间结果从点值升级为分布，最后给出结论的置信区间。多数队伍只给点值，这是最便宜的 d 层 delta。
2. **敏感性分析做全套**：单参数 ±10% 扫描 + 两参数等值线图 + tornado 图，写进模型评价节。
3. **基准对比表**：主模型 vs baseline vs 简化版，同一数据同一指标，证明"复杂度换来了什么"。没有对比的新方法没有说服力。
4. **模型假设的量化检验**：对每条关键假设做"违反时会怎样"的扰动实验，而非口头辩护。
5. **求解质量证据**：启发式算法附收敛曲线、多次独立运行的统计（均值±std）、与精确解/下界的 gap。

## 三、反模式（直接 FAIL/WARN 的写法）

- 把 SA 换成"改进的模拟退火"（只改了个降温函数）→ 纯 a 层 + 高频 baseline = WARN。
- 论文里堆 5 个模型每个跑一遍取最好 → 不叫组合创新，叫没有模型选择标准。
- "使用了先进的深度学习方法"但数据只有 30 个点 → 方法学错误，评审直接扣分。
- 新颖性声明写"本文创新性地提出了 XXX 模型"但没有数学差异陈述 → 空 delta。
