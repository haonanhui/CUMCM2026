# Stage 05 — 论文写作（Paper）

输入：建模方案.md + 求解结果报告.md + frozen_numbers.json + 图件。
目标：产出符合 CUMCM 格式规范的 LaTeX 论文 + 编译 PDF。
出口条件（G5）：LaTeX 编译通过；格式合规；数字全部可溯源。
**停点**：摘要与结论定稿须真人确认。

## 论文结构（CUMCM 标准七段+附录）

| 节 | 内容 | 素材来源 |
|---|---|---|
| 摘要 | 问题背景一句话 + 每问方法+结果一句话 + 创新点一句话 | 全文写完最后写 |
| 1 问题重述 | 用自己的话重述题目，不抄原文 | 01 分析报告 |
| 2 问题分析 | 每问的建模思路、难点、方法选择理由 | 01+02+03 |
| 3 模型假设 | 显式列出所有假设（编号），每条注明依据 | 03 建模方案 |
| 4 符号说明 | 三线表：符号/含义/单位 | 03 建模方案 |
| 5 模型建立与求解 | 每问一节：数学模型（公式）→ 求解算法 → 结果（表+图）→ 分析 | 03+04 |
| 6 模型评价 | 优点/缺点/推广方向；敏感性分析结果 | 04 验证 |
| 7 参考文献 | ≥10 篇，含方法原始文献 | 02 检索记录 |
| 附录 | 完整代码（可折叠）+ 补充图表 | 04 求解脚本 |

## 执行步骤

1. **初始化 LaTeX 项目**：
   ```bash
   cp -r paper/templates/cumcmthesis-2026/* paper/src/
   ```
   编辑 `paper/src/main.tex`，按上表分节。
2. **逐节填充**：
   - 公式用 LaTeX 行间 `equation/align` 环境，编号引用用 `\eqref{}`。
   - 数字引用：从 frozen_numbers.json 取值，禁止手填。可用 `lib/inject_numbers.py` 自动替换占位符 `{{NUM:q1_obj}}`。
   - 图件：从 `04_solve/` 复制最终图到 `paper/src/figures/`，`\includegraphics` 引用。
   - 表格：三线表（booktabs），数据来自 `04_solve/result.csv`。
3. **编译**：
   ```bash
   cd paper/src && xelatex main.tex && bibtex main && xelatex main.tex && xelatex main.tex
   ```
   编译失败 → 逐个修（常见：中文字体缺失/ctex 配置/图片路径）。
4. **摘要写作**（最后做）：
   - 300-500 字，一页内。
   - 结构：背景(1句) → 每问方法+关键数字(各1-2句) → 创新点(1句)。
   - 数字从 frozen_numbers.json 取。
   - **停点**：摘要交真人确认。
5. **结论精修**（模型评价节）：
   - 诚实写缺点与局限，不吹不藏。
   - 推广方向写"如果数据更多/约束更松可以怎样"。
   - **停点**：结论交真人确认。

## 写作纪律

- 学术写作先去元写作、报告腔、版本说明、工程术语，只保留研究对象、方法边界与结果。
- 每个论断要么有数据支撑（引用 04 产物），要么标"基于假设 X"。
- 不用"我们""本文"过多；被动语态或直述优先。
- 图表自包含：标题+轴标签+单位齐全，读者不看正文也能懂。
- 参考文献：方法原始论文优先（如 NSGA-II → Deb 2002），不用百科链接。
